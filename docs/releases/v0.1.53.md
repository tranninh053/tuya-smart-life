# Tuya Smart Life Local v0.1.53

## Điểm nổi bật

- Tự suy ra credential Tuya mobile MQTT từ phiên đăng nhập tài khoản bình thường, nên setup không còn hỏi MQTT broker, username, password, uid hoặc client id.
- Thêm hỗ trợ khóa Wi-Fi, gồm mở khóa remote qua private mobile API của Tuya và các cảm biến chẩn đoán sự kiện MQTT.
- Thêm chẩn đoán kết nối local/remote. Trạng thái local phản ánh kết nối LAN thành công; thiết bị Wi-Fi/root expose sensor local IP.
- Mapping DPS theo schema để thiết bị như atomat/công tơ hiển thị tên switch/sensor dễ đọc hơn thay vì nhãn DP tiếng Trung khi Tuya có schema code ổn định.
- Ổn định điều khiển Smart IR AC. Lệnh keydata DP `201` publish tới hub Smart IR vật lý, không gửi vào remote ảo; IR climate pause state stream của hub khi gửi `power on` kèm state yêu cầu.

## Sửa lỗi

- Đổi nhiệt IR climate không còn fallback sang nút tăng/giảm nhiệt không tồn tại khi lệnh keydata trực tiếp lỗi.
- Một lỗi command IR đơn lẻ không làm climate entity thành unavailable. Availability lấy từ cảm biến local connection của hub.
- Switch/media/light/fan của Smart IR chỉ hiện khi thiết lập được local connectivity.
- Child ảo của Smart IR không còn expose switch chung hoặc local IP sensor thuộc về hub Wi-Fi vật lý.
- Chỉ hub hiển thị diagnostic online/offline; thiết bị thường dùng cảm biến local/remote connectivity.

## Tài liệu

- Thêm ghi chú suy ra Tuya mobile MQTT và script ví dụ không phụ thuộc thư viện.
- Thêm ghi chú đường gửi Smart IR DP `201`, gồm validation LG master và yêu cầu pause state stream.
- Cập nhật README cho MQTT, khóa Wi-Fi, chẩn đoán kết nối, local IP sensor và hành vi IR command.
