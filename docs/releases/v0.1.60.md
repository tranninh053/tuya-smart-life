# Tuya Smart Life Local v0.1.60

## Điểm nổi bật

- Sửa auto-region sau login: integration ưu tiên `mobileApiUrl`/endpoint `a1-*.api.json` từ Tuya domain thay vì có thể chọn nhầm URL phụ như `px-sg.iotbing.com`.
- Khắc phục lỗi tài khoản region SG login thành công nhưng bước lấy danh sách nhà báo `USER_SESSION_INVALID`.
- Cập nhật `tools/tuya_mobile_login.py` để debug tool cũng tự đổi endpoint theo domain sau login, khớp hành vi của HACS integration.
- Bổ sung tùy chọn `--platform` cho debug tool để test đúng profile Smart Life/Tuya.
