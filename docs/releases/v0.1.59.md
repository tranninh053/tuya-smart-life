# Tuya Smart Life Local v0.1.59

## Điểm nổi bật

- Đưa lựa chọn **Ứng dụng** lên đầu màn đăng nhập để người dùng chọn Tuya hoặc Smart Life trước khi nhập tài khoản.
- Bỏ lựa chọn **Vùng API** khỏi màn đăng nhập; integration tự thử các endpoint mobile API phù hợp.
- Giữ tự động chọn signing/profile theo app đã chọn: Tuya dùng profile Tuya Smart, Smart Life dùng profile Smart Life.

## Tài liệu

- Cập nhật README, hướng dẫn setup và troubleshooting để bỏ thao tác chọn vùng thủ công.
- Cập nhật bản dịch config flow cho màn đăng nhập mới.
