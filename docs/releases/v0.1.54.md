# Tuya Smart Life Local v0.1.54

## Điểm nổi bật

- Việt hóa README và toàn bộ tài liệu markdown trong `docs/`.
- Việt hóa flow đăng nhập/cấu hình của Home Assistant: mô tả, nhãn trường, lỗi login và options flow.
- Thêm file `translations/vi.json` cho locale tiếng Việt và đồng bộ default `strings.json` sang tiếng Việt.
- Bump manifest lên `0.1.54` để HACS nhận bản phát hành tài liệu/ngôn ngữ mới.
