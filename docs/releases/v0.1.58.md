# Tuya Smart Life Local v0.1.58

## Điểm nổi bật

- Bật hỗ trợ chọn **Smart Life** ở màn đăng nhập bằng profile mobile app đã reverse từ APK Smart Life `7.9.0`.
- Tự chọn signing profile theo app đã chọn: Tuya dùng profile Tuya Smart hiện có, Smart Life dùng `clientId`, `chKey`, `ttid`, app version và native signing key riêng.
- Native signing key Smart Life được derive từ `assets/t_s.bmp`, package `com.tuya.smartlife`, certificate SHA-256 và app secret; sign output đã được verify trùng native runtime.
- Đổi login API về namespace `thing.m.user.*` giống APK Smart Life/Tuya hiện tại, thay vì prefix `smartlife.m.*`.
- Bỏ field mã vùng khỏi màn đăng nhập. Integration vẫn gửi country code mặc định nội bộ theo payload APK để giữ tương thích với Tuya/Smart Life API.

## Tài liệu

- Cập nhật README và hướng dẫn setup cho lựa chọn app Tuya/Smart Life.
- Cập nhật bản dịch config flow, không còn mô tả Smart Life là chưa hỗ trợ.

## Kiểm tra

- Verify Smart Life BMP key và native request sign bằng `tools/tuya_mobile_crypto.py`.
- Login Smart Life bằng profile mới với `tools/tuya_mobile_login.py --action homes`, trả về 2 homes.
- `python3 -m compileall custom_components/tuya_smart_life_local tools`
- `python3 -m json.tool` cho manifest, strings và các file translation.
- `git diff --check`
